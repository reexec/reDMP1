# Credits

reDMP1 stands on the work of the following projects and researchers:

* **[reexec/reCT3](https://github.com/reexec/reCT3)**, **[nworkers/reJSRF](https://github.com/nworkers/reJSRF)**, and **[reexec/rePIU](https://github.com/reexec/rePIU)**:
  Project engineering rules, dual recompilation/decompilation methodology, layered architectural guidelines, and automation pipeline structure.

* **[sp00nznet/psprecomp](https://github.com/sp00nznet/psprecomp)**:
  Allegrex MIPS/VFPU static recompilation research, `allegrexrecomp` lifting tool, and PSP ABI definitions.

* **[reexec/repsp](https://github.com/reexec/repsp)**:
  Shared portable PSP runtime, guest memory folded address management, NID dispatch engine, and HLE kernel interfaces.

* **[libsdl-org/SDL](https://github.com/libsdl-org/SDL)**:
  Cross-platform display windowing, OpenGL integration, audio output, and controller input subsystems.

* **[uOFW](https://github.com/uOFW/uOFW)** and the **[PSP Developer Wiki](https://www.psdevwiki.com/psp/)**:
  PSP hardware documentation, firmware module interfaces, and calling convention definitions.

* **[redump.org](http://redump.org/)**:
  Accurate optical disc preservation metadata, sector counts, and reference cryptographic hashes.
