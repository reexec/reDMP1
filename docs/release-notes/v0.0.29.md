# reDMP1 v0.0.29

Shortcuts the same as reCT3, with the quit shortcut shown.

Issue [#58](https://github.com/reexec/reDMP1/issues/58):

- **Request** (user, 2026-11-21): show the quit shortcut in the OSD and make every shortcut the same as reCT3.
- **Gamepad**: **LT+RT+Y** opens the menu and **LT+RT+L3+R3 held 1 s** quits (repsp v0.0.28, [reexec/repsp#61](https://github.com/reexec/repsp/issues/61)).
- **Where it is shown**: the menu header, a hint line at the end of the Graphics tab, and the Input tab's shortcut table.
- The keyboard shortcuts (Tab, Alt+1..6, Alt+Enter or double click, Ctrl+1..8) are unchanged. The README follows.

Commits from `b281512` on task branch `i058-shortcuts`, squashed into this release's merge commit.

Known limits: dialogs are not drawn on screen. Save data is plaintext.

Verified: Win64 Release (Visual Studio generator), Win64 Ninja Debug/Release and Linux x64 Debug/Release, build and CTest.
