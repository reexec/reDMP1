# reDMP1 v0.0.28

Art drawn larger than its size no longer looks blocky (texture filtering).

Issue [#56](https://github.com/reexec/reDMP1/issues/56):

- **Report** (user, 2026-11-21): at render scale 1x with the Linear output filter, art such as the song jacket looked jagged and blocky.
- **Cause**: repsp ignored the texture filter the game asks for (GE TFLT, for example linear magnification `0x000105`). The GL shader also read single texels, so the menu's Linear and anisotropic options were nearest in practice.
- **Fix**: repsp v0.0.27 follows TFLT, game-supplied mip levels and TEXLEVEL, with hardware sampling and anisotropy ([reexec/repsp#59](https://github.com/reexec/repsp/issues/59)).
- The menu's "Original" is now "Original (as the game sets it)", and the README follows.

Commits from `7bbae9a` on task branch `i056-texture-filter`, squashed into this release's merge commit.

Measured (windowed, same input script, three runs):

- No unresolved-address dispatches, no crashes.
- Present interval 18.9 ms.
- Frame dumps show the jacket, lettering and gameplay background without blocks.

Confirmed by the user.

Known limits: dialogs are not drawn on screen. Save data is plaintext.

Verified: Win64 Release (Visual Studio generator), Win64 Ninja Debug/Release and Linux x64 Debug/Release, build and CTest.
