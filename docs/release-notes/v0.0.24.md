# reDMP1 v0.0.24

An in-game settings menu (Dear ImGui), `redmp1.ini`, a stats window, a window title with FPS, and window shortcuts.

Issue [#47](https://github.com/reexec/reDMP1/issues/47).

- **Request** (user, 2026-11-18): bring over reCT3's and rexbox's in-game UI, settings, window title and shortcuts.
- **Settings menu** (Tab or LB+RB+Y, OpenGL renderer only):
  - Info: version, build, game ID and title, OpenGL, memory.
  - Graphics: rendering resolution, window size, fullscreen, VSync, aspect ratio, output filter, MSAA, texture filtering, stats items.
  - Input: keyboard and gamepad mapping tables, shortcuts.
  - The menu's height fits the tallest tab. In small windows it fits the window and scrolls.
- **Stats window**: FPS, process memory and GPU memory graphs in 0.5 s bins. Its dragged position is saved.
- **`redmp1.ini`**: next to the executable, or in the user's settings folder when that one is not writable. Command-line options win, and values set on the command line are not written to the file.
- **Window title and shortcuts**: Alt+1..6, Alt+Enter, double click, Ctrl+1..8.
- The platform side is repsp v0.0.23 ([reexec/repsp#48](https://github.com/reexec/repsp/issues/48)).

Commits from `454b7ed` on task branch `i047-overlay`, squashed into this release's merge commit.

Measured (windowed, input script to gameplay, three runs):

- Mean present interval 20.12-20.15 ms.
- No unresolved-address dispatches, no crashes.

Confirmed by the user: menu, options and shortcuts.

Known limits: dialogs are not drawn on screen. Save data is plaintext.

Verified: Win64 Debug/Release (Visual Studio generator) and Linux x64 Debug/Release, build and CTest.
