측정(**확인됨**, Win64 플러그인 빌드): 오프닝 동영상의 프레임이 디코딩되어 제작사 로고부터 표시되고, 동영상의 음성이 나온다. 타이틀에서 플레이 화면까지의 입력 스크립트 실행은 무음일 때와 같은 화면에 이르며 배경 음악이 디코딩된다. 오디오 덤프에서 클리핑과 큰 불연속은 없었다. 플러그인이나 FFmpeg 공유 라이브러리를 지운 상태에서는 무음·검은 프레임으로 정상 진행한다.

라이선스: 사용자 결정으로 `AGENTS.md`의 라이선스 규칙에 예외를 적었다(선택적 플러그인에 한해 FFmpeg LGPL 공유 빌드에 동적 링크). FFmpeg은 저장소에 없고, 기본 빌드와 CI는 FFmpeg에 의존하지 않는다.

알려진 한계: 소리가 맞게 들리는지(음정, 박자와 노트의 맞물림)는 사람이 들어 확인하지 않았다. 색 변환이 실제 기기와 같은지는 추정이다. 플러그인 빌드는 Win64에서만 검증했다. 다이얼로그를 화면에 그리지 않는다. 세이브 데이터는 평문이다.

검증: Win64와 Linux x64(WSL Ubuntu 24.04)에서 빌드와 CTest 33/33(플러그인 없는 구성, 게임 데이터가 있을 때), Win64 플러그인 구성 34/34.

# reDMP1 v0.0.11

Sound and video: background music and the opening movie play through the optional FFmpeg codec plugin.

Issue [#22](https://github.com/reexec/reDMP1/issues/22): the build option `REDMP1_CODEC_FFMPEG` (default OFF; when on, the plugin and the FFmpeg shared libraries are copied next to the executable); the plugin next to the executable is loaded at start-up (`--codec-plugin <path>`, `--no-codec-plugin`), and when it cannot be loaded one line gives the reason and the run goes on silent and black; the stop report names the real decoders; `docs/guides/codec-plugin.md` (getting FFmpeg, building, options); `THIRD_PARTY_NOTICES.md`; repsp pinned at v0.0.11 (`e698cec`). Commits from `8cd9724` on task branch `i022-codec-plugin`, squashed into this release's merge commit.

Measured (**confirmed**, Win64 plugin build): frames of the opening movie are decoded and shown, starting with the developer's logo, and the movie's audio plays. The scripted run from the title to the gameplay screen reaches the same screens as with silent decoding, with background music decoded. The audio dump showed no clipping and no large discontinuities. With the plugin or the FFmpeg shared libraries removed the run proceeds normally, silent and black.

Licence: by the user's decision an exception was recorded in the licence rules of `AGENTS.md` (the optional plugin alone links dynamically against an LGPL shared build of FFmpeg). FFmpeg is not in the repository, and the default build and CI do not depend on it.

Known limits: whether it sounds right (pitch, and how the beat lines up with the notes) has not been checked by ear. Whether the colour conversion matches the real device is assumed. The plugin build was verified on Win64 only. Dialogs are not drawn on screen. Save data is plaintext.

Verified: build and CTest 33/33 on Win64 and Linux x64 (WSL Ubuntu 24.04) in the configuration without the plugin, with game data, and 34/34 in the Win64 plugin configuration.
