측정(**확인됨**): 오프닝부터 플레이 화면까지 OpenGL로 같은 화면에 이르고 같은 그림이 나온다. 게임이 쓰는 GE 기능 가운데 OpenGL 백엔드가 지원하지 않거나 근사한 것은 없었다(통계 0). headless 측정에서 표시 간격의 평균은 소프트웨어 약 40 ms, OpenGL 약 24~27 ms였다. 오프닝 동영상(게임이 메모리에 직접 쓰는 프레임)은 두 렌더러에서 픽셀이 같다.

알려진 한계: 배경이 계속 움직이는 화면이라 전체 화면의 픽셀 일치는 확인하지 못했다. 멈춰 있는 영역의 차이는 채널당 8 이내다(OpenGL은 8비트 색, 소프트웨어는 실제 기기처럼 5비트 색). 다이얼로그를 화면에 그리지 않는다. 세이브 데이터는 평문이다. 플레이 중의 판정과 결과 화면은 아직 확인하지 않았다.

검증: Win64(작업 디렉터리에서 `scripts\build_win64.bat Release ffmpeg`, CTest 35/35)와 Linux x64(WSL Ubuntu 24.04, CTest 34/34).

# reDMP1 v0.0.12

An optional OpenGL renderer and picture scaling.

Issue [#24](https://github.com/reexec/reDMP1/issues/24): `--renderer <sw|gl>` (default `sw`; when no GL context can be created the reason is stated and the run continues with `sw`), `--scale <n>` (1 to 8, default 2; the window size and, with `gl`, the internal resolution), `--headless --renderer gl` (a hidden window); the stop report gains the renderer name, OpenGL statistics and presentation intervals; the BMP comparison tool `tools/compare_bmp.py`; the `ffmpeg` and `notest` options of `scripts/build_win64.bat`; repsp pinned at v0.0.12 (`ad7e9dd`). Commits from `9b5cc27` on task branch `i024-opengl-renderer`, squashed into this release's merge commit.

Measured (**confirmed**): from the opening to the gameplay screen the OpenGL run reaches the same screens with the same picture. None of the GE features the game uses were unsupported or approximated by the OpenGL backend (statistics at zero). In headless measurements the mean presentation interval was about 40 ms with software and about 24 to 27 ms with OpenGL. The opening movie (frames the game writes straight to memory) is pixel-identical in both renderers.

Known limits: the screens have constantly moving backgrounds, so full-screen pixel equality was not established; in still areas the difference is within 8 per channel (OpenGL blends in 8-bit colour, software in 5-bit colour like the real device). Dialogs are not drawn on screen. Save data is plaintext. Judgement during play and the result screen have not been checked yet.

Verified: Win64 (`scripts\build_win64.bat Release ffmpeg` in the working directory, CTest 35/35) and Linux x64 (WSL Ubuntu 24.04, CTest 34/34).
