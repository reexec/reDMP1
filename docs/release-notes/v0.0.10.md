측정(**확인됨**): 모드 선택에서 ○를 누르면 곡 선택 화면("Rookie Music", "1st.STAGE", DISC 01/10, 이펙터와 기어 선택, 난이도와 최고 점수)에 이르고, 다시 ○를 누르면 플레이 화면(4버튼 기어, 내려오는 노트, 판정선, 게이지, 콤보·점수 표시, 배경 애니메이션)에 이르러 계속 돈다. 플레이 중에는 우선순위 34의 악보 재생 스레드가 돈다. 배경 음악은 화면이 바뀔 때마다 ATRAC3plus 스트림을 새로 열어 오디오 채널 1로 내고, 효과음과 키음은 SAS 음성으로 채널 2에 낸다. 이 경로에서 게스트 쪽 이상(assertion, 디스패치 미스, 교착)은 없었고, 고친 것은 repsp의 GE 색 테스트 하나다(플레이 화면의 색 키 영역이 마젠타로 보이던 결함). 3회 실행 모두 플레이 화면에 이르며, 표시한 프레임 수와 GE 리스트 수는 호스트 시각에 따라 달라진다.

알려진 한계: 배경 음악(ATRAC3plus)은 무음이고 오프닝 영상은 검은 프레임이다. 다이얼로그를 화면에 그리지 않는다. 세이브 데이터는 평문이다. 플레이 중의 판정과 결과 화면은 아직 확인하지 않았다.

검증: Win64 Debug/Release와 Linux x64(WSL Ubuntu 24.04)에서 빌드와 CTest 32/32(게임 데이터가 있을 때), 게임 데이터 없는 구성도 통과.

# reDMP1 v0.0.10

Play entry: from mode select through song select into the gameplay screen.

Issue [#20](https://github.com/reexec/reDMP1/issues/20): a scripted run from mode select through song select into gameplay; `docs/analysis/scene-flow.md` (the order of screens and the input that moves on), `audio.md` (sound paths in menus and gameplay) and `first-frame.md` (descriptions and statistics of the new screens) continued; repsp pinned at v0.0.10 (`7c80806`). Commits from `19ffa9b` on task branch `i020-play-entry`, squashed into this release's merge commit.

Measured (**confirmed**): pressing ○ on mode select leads to the song select screen ("Rookie Music", "1st.STAGE", DISC 01/10, effector and gear selection, difficulty and high score), and ○ again to the gameplay screen (a four-button gear, falling notes, the judgement line, the gauge, combo and score counters, a background animation), which keeps running. A score playback thread at priority 34 runs during play. Background music opens a new ATRAC3plus stream at each screen change and goes out on audio channel 1; sound effects and key sounds are SAS voices on channel 2. No guest-side fault (assertion, dispatch miss, deadlock) appeared on this path, and the one fix was repsp's GE colour test (colour-keyed areas of the gameplay screen had shown as magenta). Three runs reach the gameplay screen; the number of presented frames and GE lists varies with host time.

Known limits: background music (ATRAC3plus) is silent and the opening movie is black frames. Dialogs are not drawn on screen. Save data is plaintext. Judgement during play and the result screen have not been checked yet.

Verified: build and CTest 32/32 (with game data) on Win64 Debug/Release and Linux x64 (WSL Ubuntu 24.04); the configuration without game data also passes.
