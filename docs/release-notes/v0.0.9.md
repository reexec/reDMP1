측정(**확인됨**): 타이틀 화면에서 START를 누르면 확인 효과음과 페이드아웃 뒤 타이틀 씬을 정리하고 모드 선택 화면("Mode Select", "ROOKIE DJING — EASY MODE", "4Buttons", 아래쪽의 EXIT/OK 안내)을 그리며 입력을 기다린다. v0.0.8의 assertion(`m_referenceCount`)은 원본 게임의 결함이 아니라 잘못 옮겨진 코드의 결과였다: 빠진 호출 때문에 스택 포인터가 32바이트 어긋난 채 씬 정리 함수로 돌아와, 해제 함수에 잘못된 인자가 전달됐다. 타이틀 화면의 마젠타 선은 repsp v0.0.9의 래스터라이저 수정으로 사라졌다. 3회 실행 모두 같은 화면에 이르며, 표시한 프레임 수와 GE 리스트 수는 호스트 시각에 따라 달라진다.

알려진 한계: 다이얼로그를 화면에 그리지 않는다. 세이브 데이터는 평문이다. 영상은 검은 프레임, ATRAC3plus 음성은 무음이다. Debug 빌드의 호스트 스택 예약은 그대로다([#16](https://github.com/reexec/reDMP1/issues/16)).

검증: Win64 Debug/Release와 Linux x64(WSL Ubuntu 24.04)에서 빌드와 CTest 32/32(게임 데이터가 있을 때), 게임 데이터 없는 구성도 통과.

# reDMP1 v0.0.9

Menu entry: a lifter fix takes the run past the title screen to the mode select screen.

Issue [#18](https://github.com/reexec/reDMP1/issues/18): local lifter patch `0003-jalr-fallthrough`, fixing `jalr` being treated like `jr` as the end of a body, which dropped the fall-through call into the next function for bodies ending in `jalr` (regeneration required); an optional diagnostic build `REDMP1_TRACE_GUEST` that logs entry to the reference count functions (`REDMP1_TRACE_REFCOUNT=1` at run time); `REDMP1_GENERATED_DIR` to relocate the generated code; `docs/analysis/scene-flow.md` (the path from the title to mode select, the reference-counted object, the assertion's condition); repsp pinned at v0.0.9 (`f04d9ff`). Commits from `05e826d` on task branch `i018-menu-entry`, squashed into this release's merge commit.

Measured (**confirmed**): pressing START on the title screen plays the confirm sound, fades out, tears down the title scene and draws the mode select screen ("Mode Select", "ROOKIE DJING — EASY MODE", "4Buttons", the EXIT/OK hints at the bottom), then waits for input. The assertion seen in v0.0.8 (`m_referenceCount`) was not a fault of the original game but a result of mislifted code: because of the missing call, control returned to the scene teardown function with the stack pointer 32 bytes off, passing a wrong argument to a release function. The magenta lines on the title screen are gone with the rasterizer fix in repsp v0.0.9. Three runs reach the same screen; the number of presented frames and GE lists varies with host time.

Known limits: dialogs are not drawn on screen. Save data is plaintext. Video is black frames and ATRAC3plus audio is silent. The host stack reservation for Debug builds remains ([#16](https://github.com/reexec/reDMP1/issues/16)).

Verified: build and CTest 32/32 (with game data) on Win64 Debug/Release and Linux x64 (WSL Ubuntu 24.04); the configuration without game data also passes.
