# reDMP1 v0.0.18

The local lifter patches submitted upstream, and the local patches replaced by the submitted versions.

Issue [#36](https://github.com/reexec/reDMP1/issues/36): with the user's permission (2026-11-16) the local psprecomp patches went upstream. 0004 (a `j` to a function entry in the same body becomes a `goto`) is [sp00nznet/psprecomp#35](https://github.com/sp00nznet/psprecomp/pull/35); 0001+0002 (relocating a PRX to a chosen base) were rewritten and submitted as [#36](https://github.com/sp00nznet/psprecomp/pull/36); 0003 (continuing after a linking `jalr`) duplicates another contributor's [#31](https://github.com/sp00nznet/psprecomp/pull/31), so it was not submitted and the local patch follows #31's condition (`jalr $zero` ends a body). The local patches are now the submitted versions and the code is regenerated. `regenerate.py` uses the most recently built lifter and prints its path; `lift_invariance` compares two relocated bases; `lift_audit.py` counts data read as code separately. Commits from `7681300` on task branch `upstream-sync`, squashed into this release's merge commit.

Found on the way: the former 0001's `main.c` change had turned em dashes (`—`) into `??`, deleted two upstream comments and re-implemented export and pointer collection that upstream already has; the submitted version fixes all of it. Also, `regenerate.py` could pick a lifter from a stale build directory (built 13 November, without patches 0003 and 0004); this surfaced now, and no code made with it was ever committed.

Measured (**confirmed**): the submitted version collects pointer seeds on the relocated path through upstream's `looks_like_code` filter (the former local patch accepted `.text` only). Functions went from 8,785 to 9,024: of the 239 added, 22 are real code inside `.text`, and 217 lie after `.text`, 204 of them data read as code (never called). Three scripted runs to gameplay reached the same screens with zero undiscovered-address dispatches.

Known limits: data read as code is present in the generated code (harmless; restricting seeds to `.text` could be proposed upstream separately). 148 tail-call cycles across functions (the trampoline, [#33](https://github.com/reexec/reDMP1/issues/33)). Dialogs are not drawn on screen. Save data is plaintext.

Verified: Win64 Release (FFmpeg plugin) and Debug, and Linux x64 Debug/Release, build and CTest (including `lift_invariance`). repsp is unchanged.
