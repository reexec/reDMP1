측정(**확인됨**): 오프닝을 건너뛰면 게임은 "NOW LOADING" 뒤에 세이브 데이터를 자동 읽기로 부른다. 세이브가 없으면 "no data" 결과를 받고 메시지 다이얼로그로 세이브를 만들지 묻는다. "예"면 자동 쓰기로 6,284바이트 데이터 파일과 `PARAM.SFO`, 아이콘, 배경을 만들고, "아니오"면 쓰지 않는다. 세이브가 있으면 다이얼로그 없이 읽는다. 세 경우 모두 타이틀 화면(스피커 배경, 원형 엠블럼, "PORTABLE" 로고, "PRESS START BUTTON", 저작권 표시)을 그리며 입력을 기다린다. 이 구간에서 게임이 import하는 20개 라이브러리의 미구현 호출은 없다. 3회 실행의 유틸리티 호출과 결과는 같고, 표시한 프레임 수와 GE 리스트 수는 호스트 시각에 따라 달라진다.

알려진 한계: 다이얼로그를 화면에 그리지 않는다. 세이브 데이터는 평문이다. 타이틀 화면에 1픽셀 폭의 마젠타 선이 몇 개 보인다(렌더러 결함). 타이틀 화면에서 START를 누르면 게임 내부 assertion으로 종료한다(다음 과제). 영상은 검은 프레임, ATRAC3plus 음성은 무음이다.

검증: Win64 Debug/Release와 Linux x64(WSL Ubuntu 24.04)에서 빌드와 CTest 32/32(게임 데이터가 있을 때), 게임 데이터 없는 구성 25/25.

# reDMP1 v0.0.8

Utility wired in: save data created and loaded, running on to the title screen.

Issue [#15](https://github.com/reexec/reDMP1/issues/15): repsp's sceUtility HLE registered in the app, utility statistics in the stop report; `--save-dir` for the save data directory (default `savedata/` under the per-user data directory) and `--dialog-answer` for undrawn yes/no dialogs; CTest uses a save directory inside the build directory, emptied before `app_boot`; `docs/analysis/savedata.md` (modes, names, sizes, branches, dialog text); repsp pinned at v0.0.8 (`abcfa69`). Commits from `08c4756` on task branch `i015-utility`, squashed into this release's merge commit.

Measured (**confirmed**): with the opening skipped, the game calls save data auto-load after "NOW LOADING". Without save data it gets the "no data" result and asks through a message dialog whether to create it: on "yes" an auto-save writes a 6,284-byte data file, `PARAM.SFO`, an icon and a background; on "no" nothing is written. With save data present it loads without a dialog. In all three cases it draws the title screen (speaker background, round emblem, "PORTABLE" logo, "PRESS START BUTTON", copyright line) and waits for input. Nothing in this stretch calls an unimplemented function in any of the 20 imported libraries. Three runs give the same utility calls and results; the number of presented frames and GE lists varies with host time.

Known limits: dialogs are not drawn on screen. Save data is plaintext. A few one-pixel magenta lines show on the title screen (a renderer defect). Pressing START on the title screen ends in an assertion inside the game (the next task). Video is black frames and ATRAC3plus audio is silent.

Verified: build and CTest 32/32 (with game data) on Win64 Debug/Release and Linux x64 (WSL Ubuntu 24.04), and 25/25 in the configuration without game data.
