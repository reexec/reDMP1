* [repsp: PSP 메모리 맵 (psp-memory-map.md)](https://github.com/reexec/repsp/blob/main/docs/kb/psp-memory-map.md)
* [repsp: PARAM.SFO 바이너리 포맷 (param-sfo.md)](https://github.com/reexec/repsp/blob/main/docs/kb/param-sfo.md)
* [repsp: PSP NID 명명 규칙 및 계산 원리 (nid.md)](https://github.com/reexec/repsp/blob/main/docs/kb/nid.md)
