# 작업 로그: 커널 HLE 기반 초기 부팅 (`i005-boot`)

## 1. 작업 요약

[설계 문서](../design/20261114-i005-boot.md)와 [작업 지시서](../work-orders/20261114-i005-boot.md)에 따라 `redmp1 <game_dir>` 기본 실행 경로를 커널·UMD HLE와 배턴 스케줄러 위에 연결하고 초기 부팅을 검증했다.

1. **`lift.json` `start_thread` 기본값 추가 (`f3185f8`)**
   - `priority: 32`, `stack_size: 262144`, `attr: 0` (출처: uOFW `modulemgr`) 추가.
2. **기본 커널 HLE 부팅 경로 및 정지 분류 구현 (`16524d8`)**
   - `CMakeLists.txt`에서 `redmp1`에 `repsp::hle_kernel` 링크.
   - `src/app/main.cpp` `RunBoot()`: `LoadPrx` 후 `disc0:`/`umd0:`(읽기 전용)과 `ms0:`(읽기/쓰기, `GetUserDataDirectory("redmp1") / "ms0"`) 마운트, `repsp::hle::kernel::Register(cfg)`, `Scheduler::CreateThread("module_start", ...)` 및 `GuardedRun` 실행, 3종 정지 분류 `(a)`/`(b)`/`(c)` 및 종료 코드(`0`, `10`/`11`, `12`), `PrintKernelSummary()` 출력.
3. **`app_boot` CTest 추가 (`6c62b03`)**
   - `roms/`가 존재하는 로컬 환경에서 `app_boot` 테스트가 `Class: (a)`와 종료 코드 `0`을 검증하도록 등록.
4. **부팅 중 발견한 `repsp` 커널 결함 수정 (`third_party/repsp` 브랜치 `i005-kernel-hle`, 커밋 `0e8ae98`)**
   - 증상: `user_main` 진입 직후 `0x088043A4`의 `sw $s1, 4($k0)`에서 접근 위반(`r_k0 == 0`), 이어서 `0x088BF4C0`이 `892($s1)` 미초기화 스택을 `0`으로 읽어 `0x00000148` 접근 위반 발생.
   - 수정: `Scheduler::CreateThread`에서 PSP `ThreadMan` 규약에 따라 스택을 기본 `0xFF`로 채우고(`NO_FILLSTACK`/`CLEAR_STACK` 플래그 존중), `Scheduler::StartThread`에서 스택 상단에 256바이트 0 초기화된 `$k0` TLS 블록을 배치해 `kRegK0 = 26`에 설정.
5. **분석·아키텍처·실행 가이드 문서화 (`6b88b74`)**
   - [boot.md](../analysis/boot.md), [analysis/README.md](../analysis/README.md), [executable.md](../analysis/executable.md), [ARCHITECTURE.md](../../ARCHITECTURE.md), [running-and-tracing.md](../guides/running-and-tracing.md) 작성·갱신.

# Work Log: Initial Boot on Kernel HLE (`i005-boot`)

## 1. Work Summary

Connected the default `redmp1 <game_dir>` path to `repsp::hle::kernel` and the baton scheduler per [the design document](../design/20261114-i005-boot.md) and [the work order](../work-orders/20261114-i005-boot.md), and verified initial boot through the first non-kernel HLE stop.

1. Added `start_thread` defaults (`priority: 32`, `stack_size: 262144`, `attr: 0`, source `uOFW modulemgr`) to `lift.json` (`f3185f8`).
2. Linked `repsp::hle_kernel` and implemented `RunBoot` with `disc0:`/`umd0:`/`ms0:` mounts, 3-class stop classification `(a)`/`(b)`/`(c)`, and `PrintKernelSummary()` (`16524d8`).
3. Added `app_boot` CTest when `roms/` is present (`6c62b03`).
4. Fixed a kernel defect uncovered during boot in `third_party/repsp` (`i005-kernel-hle`, `0e8ae98`): initialized the 256-byte `$k0` TLS block in `StartThread` and filled thread stacks with `0xFF` by default in `CreateThread`.
5. Added/updated [boot.md](../analysis/boot.md), [analysis/README.md](../analysis/README.md), [executable.md](../analysis/executable.md), [ARCHITECTURE.md](../../ARCHITECTURE.md), and [running-and-tracing.md](../guides/running-and-tracing.md) (`6b88b74`).
