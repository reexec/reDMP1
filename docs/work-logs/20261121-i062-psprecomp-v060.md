## 1. 작업 내용

첫 커밋(`a11f268`: `third_party/psprecomp` submodule을 `14749c1` v0.6.0으로 이동, 로컬 패치 `0001`/`0003`/`0004`/`0006` 삭제, `0005-emit-trampoline.patch`를 `d9278d2`로 재생성, `CMakeLists.txt` 패치 목록 갱신)에 이어 작업 지시의 1~5단위를 수행했다.

1. **패치 README 갱신 (`patches/psprecomp/README.md`)**:
   - 기준 커밋을 `14749c1`(upstream `v0.6.0`)으로 갱신했다.
   - upstream 상태 표에 합쳐진 패치(`0001`, `0003`, `0004`, `0006`)를 `"v0.6.0에 들어감"`으로 남기고, `0005`는 v0.6.0 rebase(`d9278d2`) 상태로 갱신했다.
   - 패치 설명에는 남은 `0005-emit-trampoline.patch`만 두고 `#32` 형식(`psp_call_guest_fn`/`psp_call_guest_addr`)을 반영했다.
2. **ABI 어댑터와 probe (`src/recomp_abi/dispatch.c`, `src/recomp_abi/README.md`, `tests/recomp_abi_probe.cpp`)**:
   - `src/recomp_abi/dispatch.c`에 `PSP_NOINLINE`(`__declspec(noinline)` / `__attribute__((noinline))`)로 `psp_call_guest_fn(psp_fn_t fn, uint32_t return_site)`와 `psp_call_guest_addr(uint32_t addr, uint32_t return_site)`를 추가했다. 각각 `psp_frame`을 스택에 push/pop하고 `psp_run`/`psp_dispatch`를 부른 뒤, `psp_cpu.unwind == return_site`일 때만 `psp_cpu.unwind = 0`으로 지운다.
   - `src/recomp_abi/README.md`의 `dispatch.c` 심볼 표를 현재 구현에 맞게 갱신했다.
   - `tests/recomp_abi_probe.cpp`에 9번 검증 항목을 추가했다: `psp_call_guest_fn`·`psp_call_guest_addr`의 `psp_next` 꼬리 체인 완주, `psp_cpu.frame` 복구, 자기 `return_site` unwind 정리, 바깥 `return_site` unwind 보존, 미등록 주소 호출 시 dispatch miss 보고.
3. **lifter 빌드, 재컴파일 코드 재생성, diff 확인**:
   - Win64 Ninja Release 빌드 디렉터리에서 새 `allegrexrecomp`와 `recomp_abi_probe`를 빌드하고 `recomp_abi_probe.exe` 통과를 확인했다.
   - `ALLEGREXRECOMP`를 방금 빌드한 `allegrexrecomp.exe`로 지정해 `python scripts/recomp/regenerate.py`를 실행했다(`9024` functions, `17232` interior entries, `144` imports, `219/190497` VFPU traps, 141/144 파일 변경).
   - 재생성 전 사본과 새 생성 코드의 diff를 주소·함수명 정규화 후 집계해 설계 §2의 표와 건수 단위로 정확히 일치함을 확인했다:
     - `psp_run(psp_func_X)` -> `psp_call_guest_fn(psp_func_X, ret)`: **10,933**건
     - `psp_import_X()` -> `psp_call_guest_fn(psp_import_X, ret)`: **699**건
     - `psp_dispatch(_t)` -> `psp_call_guest_addr(_t, ret)`: **400**건
     - `psp_dispatch(X); /* not discovered */` -> `psp_call_guest_addr(X, ret); /* not discovered */`: **10**건
     - 헤더(`dmp1_funcs.h`): **1**건 (`PSP_CALL_BEGIN`/`PSP_CALL_END`가 프레임 push/pop을 제거하고 unwind 전파만 수행, `#ifdef PSPRECOMP_LOOP_HOOK` 위 upstream `#38` 주석 4줄 추가)
     - 그 외 변경 없음.
