## 4. 질문 및 후속 관찰

1. **선택적 타이틀 화면 `START` 입력 이후 `Instance.cpp:37` assert**:
   * 설계 §2의 선택 단계로 타이틀 화면에서 VBlank 550에 `START`를 한 번 더 누르면(`%TEMP%\redmp1-build\skip-movie.txt`), `sceSasCore`로 확인 효과음이 재생되고 페이드아웃(~25프레임) 뒤 씬 정리 중 `sceKernelSetEventFlag(0xF, 2)` 직후 `[guest stdout] assertion "m_referenceCount" failed: file "Instance.cpp", line 37`과 `sceKernelFreePartitionMemory(0x7)`를 거쳐 `module self-unload`(`Exit code: 11`)로 종료된다. 다음 이슈(메뉴 진입) 진행 전에 이 reference count 불일치가 `repsp` HLE 반환값/타이밍 문제인지 게스트/lifter 문제인지 원인 분석이 필요하다.
2. **타이틀 화면 마젠타(`#FF00FF`) 1픽셀 경계선**:
   * `frame_0175`..`0405`에서 중앙 원형 엠블럼 아래쪽과 오른쪽 삼각형 화살표 옆에 1픽셀 폭의 `#FF00FF` 선이 보인다. GE 컬러키/알파 테스트 또는 텍스처 경계 클램핑 동작을 후속 GE 개선 이슈에서 점검할 가치가 있다.
