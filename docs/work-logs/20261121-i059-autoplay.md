### 단위 4~5: 게임 검증 및 롱노트 형식 확인·반영
* **롱노트 형식 확인(확인됨)**:
  * 첫 전체 곡 실행(`바람에게 부탁해`, 일반 노트 146 + 롱노트 3)에서 `MAX 0146 / BREAK 0003 / COMBO 00117`을 확인하고, 채보 메모리와 생성 코드 `0x08866370`–`0x08866388`을 대조해 롱노트 형식을 확인했다.
  * 롱노트도 `type == 1`이며, 노트 오프셋 **`+14`(비정렬 `u16`, 리틀 엔디안)** 가 지속 시간(채보 틱 단위)이다.
  * 게임 코드 `0x08866384`(`sltiu $v0, $v0, 7`) 기준으로 지속 시간이 **`< 7`**(일반 노트는 `6`)이면 단타 노트, **`>= 7`**(예: `144`)이면 **롱노트**다.
  * 끝 시각은 `note_time + duration`이다.
* **롱노트 처리 반영**:
  * `autoplay.{h,cpp}`에서 `duration >= 7`인 노트를 만나면 시작 프레임에 누르고 `now < note_time + duration` 동안 유지한 뒤, `now >= note_time + duration` 프레임에 떼도록 구현했다(`redmp1_autoplay_probe`에 롱노트 케이스 추가).
* **전체 곡 재검증** (`redmp1.exe roms --renderer gl --autoplay --max-vblanks 8500 --input-script <keysound-script>`):
  * 결과 화면 덤프(`REPSP_FRAME_DUMP`, 확인 후 삭제)에서 **`STAGE CLEARED! / MAX 0149 / BREAK 0000 / COMBO 00149 / 100.0% / S / NEW RECORD! 0032463`** 확인.
  * `Dispatches: 0`, `Exit=0`, `Present: 7970 frames (mean=17.79 ms)`, `OpenGL unsupported=0`.

## 1. Summary of Changes by Unit

### Unit 1: `repsp #63` Button Filter and `ctrl_probe`
* `third_party/repsp/include/repsp/hle/ctrl.h`, `third_party/repsp/src/hle/ctrl/hle_ctrl.cpp`:
  * Added `repsp::hle::ctrl::SetButtonFilter(ButtonFilterFn fn)` (default `nullptr`).
  * Invoked the filter inside `HleReadBufferPositive` on the guest thread right before `WriteBlock`. Input recording (`--input-record`) logs raw pre-filter buttons in `ProduceSample` and is unaffected by the filter.
  * Cleared the filter in `Register()` and `Shutdown()`.
* `third_party/repsp/tools/ctrl_probe/main.cpp`: Added Check 8 verifying filter transformation, restoration when cleared, and pre-filter-only input recording.
* `third_party/repsp/ARCHITECTURE.md`: Documented `SetButtonFilter` in §2.10.

### Unit 2: `reDMP1` Autoplay Module and Synthetic-Memory Probe
* `src/app/autoplay.h`, `src/app/autoplay.cpp`:
  * Consolidated all game-structure constants (`0x0891D74C` current scene, `0x088ED7A0` gameplay vtable, `0x0891E4DB`/`0x0891E58F` layout/flag, judge `G`, score `S`, chart `C`, channel arrays, note offsets) into `autoplay_layout`, each commented with its design §2 / binary basis.
  * Active only in the gameplay scene; clears human lane buttons (including L/R when `flag == 1`) while preserving non-lane buttons (such as START).
  * Tracks per-lane cursors, presses notes at `note_time <= now + d/2`, releases tap notes on the next call, resets cursors on song change or scene exit, and logs once before skipping unsupported note types.
* `src/app/autoplay_probe.cpp`, `CMakeLists.txt`: Added `redmp1_autoplay_probe` verifying non-gameplay passthrough, 4K/6K/8K layouts, single-frame press + release, back-to-back notes, long-note hold + release, and lane-button clearing with START preserved.

### Unit 3: Menu and `--autoplay`
* `src/app/settings_ui.h`, `src/app/settings_ui.cpp`:
  * Added the `Autoplay` checkbox and one-line note (`Plays notes automatically. High scores are saved as usual.`) at the top of the `Input` tab.
  * Added a small top-right `AUTOPLAY` badge drawn during gameplay whenever autoplay is enabled (menu open or closed).
  * Always starts off per run and is not saved to `redmp1.ini`.
* `src/app/main.cpp`: Added `--autoplay` CLI option and wired `repsp::hle::ctrl::SetButtonFilter` to `Autoplay::FilterButtons` (cleared on shutdown).

### Units 4-5: Game Check and Long-Note Format Confirmation
* **Long-note format (confirmed)**:
  * The initial full-song run (`Wind Tales`, 146 tap notes + 3 long notes) yielded `MAX 0146 / BREAK 0003 / COMBO 00117`. Inspecting chart memory and generated code (`0x08866370`–`0x08866388`) confirmed that long notes also have `type == 1` and store their duration in chart ticks as an unaligned little-endian **`u16` at offset `+14`**.
  * Per `0x08866384` (`sltiu $v0, $v0, 7`), `duration < 7` (6 for normal notes) is a tap note and **`duration >= 7`** (e.g. `144`) is a **long note** ending at `note_time + duration`.
* **Long-note handling**:
  * Updated `autoplay.{h,cpp}` to hold long notes (`duration >= 7`) while `now < note_time + duration` and release once `now >= note_time + duration`, with a matching test in `redmp1_autoplay_probe`.
* **Full-song re-check** (`redmp1.exe roms --renderer gl --autoplay --max-vblanks 8500 --input-script <keysound-script>`):
  * Verified on the result screen dump (`REPSP_FRAME_DUMP`, deleted after check): **`STAGE CLEARED! / MAX 0149 / BREAK 0000 / COMBO 00149 / 100.0% / S / NEW RECORD! 0032463`**.
  * `Dispatches: 0`, `Exit=0`, `Present: 7970 frames (mean=17.79 ms)`, `OpenGL unsupported=0`.
