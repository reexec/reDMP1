   * `third_party/repsp/include/repsp/platform/overlay.h`, `src/platform/sdl/display_sdl_internal.h`, `overlay_sdl.cpp`, `sdl_platform.cpp`: `SetOverlayBuilder`, `RenderOverlay`, `OverlayVisible`, `SetOverlayVisible`를 구현했다. 3. **repsp 3단계 (표시/GL 옵션, 통계 원천)**
   * `display.h`, `sdl_platform.cpp`: `SetWindowScale`, `SetFullscreen`, `IsFullscreen`, `SetVsyncMode`(`Off`/`On`/`Adaptive`), `GetSwapInterval`, `SetAspectMode`(`Original`/`Stretch`/`Integer`), `SetOutputFilter`(`Nearest`/`Linear`), `ComputeOutputRect`, `GetDisplayFps`, `GetDisplayGlInfo`, `GetProcessMemoryBytes`를 구현했다.
   * `render_backend.h`, `gl_functions.h`, `gl_backend.cpp`: `SetMsaaSamples`(`0/2/4/8`, `GL_MAX_SAMPLES` 이하 클램핑, render-to-texture 샘플링 전 및 flush 종료 시 `glBlitFramebuffer` resolve), `SetTextureFilterMode`(`Original`/`Linear`/`Aniso2x..16x`), `GetGpuMemoryInfo`(드라이버 보고 시 사용량/총량, 미보고 시 HLE 텍스처·FBO 합계)를 구현했다.
4. **reDMP1 (`redmp1.ini`, 설정 UI, 통계 창)**
   * `src/app/settings.h`, `src/app/settings.cpp`: 실행 파일 옆 `redmp1.ini` 읽기/원자적 저장(`.tmp` + `rename`)과 쓰기 실패 시 사용자 데이터 폴더 폴백을 구현했다.
   * `src/app/settings_ui.h`, `src/app/settings_ui.cpp`: `Info`(빌드·게임 ID/제목·OpenGL·메모리), `Graphics`(3.5 옵션 + `Tracked` 적용 상태 + 통계 항목 토글), `Input`(키보드·게임패드 매핑표·단축키) 탭과 드래그 가능한 통계 그래프 창(0.5초 고정 구간 FPS·메모리·GPU 메모리)을 구현했다.
   * `src/app/main.cpp`, `CMakeLists.txt`: `--scale` 등 명령줄 옵션이 `redmp1.ini`보다 우선하되 파일에 덮어쓰지 않도록 연결했다.

## 3. 확인 사항 / 질문

* GPU 메모리 드라이버 조회는 OpenGL `GL_NVX_gpu_memory_info` 확장이 있으면 드라이버 사용량/총량을 표시하고, 없으면 HLE가 만든 텍스처·FBO 합계에 `(HLE)` 표기를 붙여 보여 주도록 정했습니다.
* MSAA는 `UiResolveTargetIfDirty`로 render-to-texture 샘플링 직전과 flush 종료 시 resolve하므로 render-to-texture 화면에서도 깨지지 않으며, 사용자가 창 모드에서 메뉴·단축키·옵션을 최종 확인할 수 있습니다.

## 1. Changes by Unit

1. **repsp Step 1 (Dear ImGui, overlay contract, input withholding)**
   * `third_party/repsp/CMakeLists.txt`: Added the `imgui` (`repsp::imgui`) static library from `third_party/imgui` (`v1.93.0`, excluded from strict warning flags) and linked it `PUBLIC` to `repsp_platform` so the app can include `imgui.h` directly.
   * `third_party/repsp/include/repsp/platform/overlay.h`, `src/platform/sdl/display_sdl_internal.h`, `overlay_sdl.cpp`, `sdl_platform.cpp`: Implemented `SetOverlayBuilder`, `RenderOverlay`, `OverlayVisible`, and `SetOverlayVisible`. ImGui is created only for visible OpenGL windows (`--headless` and software renderer never initialize it), toggled by `Tab` or gamepad `LB+RB+Y`, and withholds game input while open.
2. **repsp Step 2 (Window title/FPS, shortcuts)**
   * `third_party/repsp/include/repsp/platform/display.h`, `src/platform/sdl/sdl_platform.cpp`: Added `SetDisplayTitle`, `SetRenderScaleCallback`, and pure helpers `ClassifyShortcut` / `ShouldBlockGameKeyboardInput`.
   * Window titles are updated exclusively on the UI thread about once per second from actual presents using `<app title> - OpenGL <major>.<minor> - FPS : <n.n>` or `<app title> - Software - FPS : <n.n>`.
   * Implemented `Alt+1..6` (1x..6x of 480x272 after leaving fullscreen/maximized), `Alt+Enter` / left double-click outside open overlay windows (borderless fullscreen), `Ctrl+1..8` (internal render scale), and blocked `Alt`/`Ctrl` keyboard chords from leaking into game input.
3. **repsp Step 3 (Display/GL options, telemetry sources)**
   * `display.h`, `sdl_platform.cpp`: Added `SetWindowScale`, `SetFullscreen`, `IsFullscreen`, `SetVsyncMode` (`Off`/`On`/`Adaptive`), `GetSwapInterval`, `SetAspectMode` (`Original`/`Stretch`/`Integer`), `SetOutputFilter` (`Nearest`/`Linear`), `ComputeOutputRect`, `GetDisplayFps`, `GetDisplayGlInfo`, and `GetProcessMemoryBytes`.
   * `render_backend.h`, `gl_functions.h`, `gl_backend.cpp`: Added `SetMsaaSamples` (`0/2/4/8` clamped to `GL_MAX_SAMPLES`, resolved via `glBlitFramebuffer` before render-to-texture sampling and at flush end), `SetTextureFilterMode` (`Original`/`Linear`/`Aniso2x..16x`), and `GetGpuMemoryInfo` (driver-reported via `GL_NVX_gpu_memory_info` when available, otherwise HLE texture + FBO bytes).
4. **reDMP1 (`redmp1.ini`, settings UI, stats window)**
   * `src/app/settings.h`, `src/app/settings.cpp`: Added `redmp1.ini` loading and atomic saving (`.tmp` + `rename`) beside the executable with fallback to the user data directory on write failure.
   * `src/app/settings_ui.h`, `src/app/settings_ui.cpp`: Added `Info`, `Graphics` (all options with `Tracked` "applying" state and stats toggles), and `Input` tabs, plus a draggable stats overlay (0.5 s binned FPS, process memory, GPU memory).
   * `src/app/main.cpp`, `CMakeLists.txt`: Wired CLI precedence (`--scale`, `--renderer` override the file for that run without overwriting it).
