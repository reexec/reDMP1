## 1. 변경 요약

### `repsp` (`third_party/repsp`, 브랜치 `i61-shortcuts`)

1. **결정적 게임패드 단축키 상태 판정 분리 (`include/repsp/platform/overlay.h`)**
   * `kGamepadTriggerDownThreshold = 16384`, `kGamepadQuitHoldMs = 1000` 상수와 `GamepadShortcutInput`, `GamepadShortcutState`, `GamepadShortcutResult`, 순수 함수 `UpdateGamepadShortcuts(state, input, now_ms, allow_menu)`를 추가했다.
   * `LT+RT`가 모두 `16384`를 초과하면 메뉴 닫힘 여부와 무관하게 `withhold_y`/`withhold_l3`/`withhold_r3`를 세워 게임 입력으로 전달되지 않게 했다.
   * `LT+RT+Y`는 누르는 순간 한 번 `toggle_menu`(`allow_menu == true`일 때만), `LT+RT+L3+R3`는 1000 ms 이상 유지 시 누름당 한 번 `request_quit`을 낸다.
2. **SDL 오버레이·입력·종료 경로 연동 (`src/platform/sdl/display_sdl_internal.h`, `overlay_sdl.cpp`, `sdl_platform.cpp`)**
   * `PollGamepadShortcuts()`가 `LT+RT+Y` 메뉴 토글(OpenGL 창 존재 시에만)과 `LT+RT+L3+R3` 1초 종료 요청(OpenGL·소프트웨어 렌더러 모두)을 처리하고 종료 시 `[overlay] quit requested (LT+RT+L3+R3)`를 출력하도록 수정했다.
   * `sdl_platform.cpp`에서 `request_quit` 시 창 닫기와 동일한 `close_requested_.store(true)` 경로로 종료하고, `UpdateInputSnapshotFromSdl`에서 `withhold_y`/`withhold_l3`/`withhold_r3`에 해당하는 게임패드 버튼을 차단하도록 했다.
   * `OverlayProcessEvent()`는 OpenGL 오버레이 창이 없는 소프트웨어 렌더러에서는 `Tab`을 무시하도록 가드를 추가했다.
3. **probe 및 문서 (`tools/platform_probe/main.cpp`, `ARCHITECTURE.md`)**
   * `platform_probe`에 Check 8을 추가해 창·SDL·스레드 타이밍 없이 `LT+RT+Y` 1회 토글, `allow_menu=false` 비토글, `LT+RT+L3+R3` 1초 미만 미종료·1초 시 1회 종료·지속 유지 시 재발화 없음·해제 후 재시작, `LT+RT` 미입력 시 Y/L3/R3 통과를 결정적으로 검증했다.
   * `ARCHITECTURE.md` §2.14의 단축키 설명을 `LT+RT+Y` 및 `LT+RT+L3+R3` 1초 종료로 갱신했다.

### `reDMP1` (브랜치 `i058-shortcuts`)

1. **내부 설정 UI (`src/app/settings_ui.cpp`)**
   * 메뉴 머리말을 `"Tab (LT+RT+Y on a gamepad) closes this menu. The game keeps running without input."`으로 수정했다.
   * `Graphics` 탭 끝에 `Shortcuts: Ctrl+1..8 resolution, Alt+Enter or double click fullscreen, Alt+1..6 window size. Gamepad: LT+RT+Y menu, LT+RT+L3+R3 held 1 s quits.` 안내 문구를 추가했다.
   * `Input` 탭 단축키 표를 `Tab / LT+RT+Y — Open / close settings menu`와 `LT+RT+L3+R3 (hold 1 s) — Quit` 포함으로 갱신했다.
2. **문서 (`README.md`, 작업 로그)**
   * 한국어·영어 단축키 안내에 `LT+RT+Y` 및 `LT+RT+L3+R3`(1초 누르기 종료)를 반영했다.

# Work Log: Shortcuts Aligned with reCT3 (issue #58, repsp #61)

* Date: 2026-11-21
* Branches: `reDMP1` `i058-shortcuts`, `repsp` `i61-shortcuts`
* Design: [20261121-i058-shortcuts.md](../design/20261121-i058-shortcuts.md)

## 1. Summary of Changes

### `repsp` (`third_party/repsp`, branch `i61-shortcuts`)

1. **Deterministic gamepad shortcut state machine (`include/repsp/platform/overlay.h`)**
   * Added `kGamepadTriggerDownThreshold = 16384`, `kGamepadQuitHoldMs = 1000`, `GamepadShortcutInput`, `GamepadShortcutState`, `GamepadShortcutResult`, and the pure function `UpdateGamepadShortcuts(state, input, now_ms, allow_menu)`.
   * While both `LT` and `RT` exceed `16384`, `withhold_y`/`withhold_l3`/`withhold_r3` are set even when the overlay is closed.
   * `LT+RT+Y` toggles the menu once on press (when `allow_menu == true`); `LT+RT+L3+R3` held for 1000 ms requests quit once per hold.
2. **SDL overlay, input, and quit integration (`src/platform/sdl/display_sdl_internal.h`, `overlay_sdl.cpp`, `sdl_platform.cpp`)**
   * Updated `PollGamepadShortcuts()` to handle `LT+RT+Y` (OpenGL only) and `LT+RT+L3+R3` 1 s quit (both OpenGL and software renderers), logging `[overlay] quit requested (LT+RT+L3+R3)` when triggered.
   * Wired `request_quit` in `sdl_platform.cpp` to `close_requested_.store(true)` (the same path as closing the window) and withheld gamepad `Y`/`L3`/`R3` in `UpdateInputSnapshotFromSdl` while `LT+RT` are held.
   * Guarded `OverlayProcessEvent()` so `Tab` does nothing when no OpenGL overlay window exists.
3. **Probe and documentation (`tools/platform_probe/main.cpp`, `ARCHITECTURE.md`)**
   * Added Check 8 in `platform_probe` to deterministically verify without a window, SDL, or thread timing: single toggle on `LT+RT+Y`, no toggle when `allow_menu=false`, no quit under 1 s, single quit at 1 s, no repeat while held, timer reset on release, and Y/L3/R3 passing through without `LT+RT`.
   * Updated `ARCHITECTURE.md` §2.14 for `LT+RT+Y` and `LT+RT+L3+R3` 1 s quit.

### `reDMP1` (branch `i058-shortcuts`)

1. **In-game settings UI (`src/app/settings_ui.cpp`)**
   * Updated the menu header to `"Tab (LT+RT+Y on a gamepad) closes this menu. The game keeps running without input."`
   * Added the shortcut hint line at the bottom of the `Graphics` tab: `Shortcuts: Ctrl+1..8 resolution, Alt+Enter or double click fullscreen, Alt+1..6 window size. Gamepad: LT+RT+Y menu, LT+RT+L3+R3 held 1 s quits.`
   * Updated the `Input` tab shortcut table with `Tab / LT+RT+Y — Open / close settings menu` and `LT+RT+L3+R3 (hold 1 s) — Quit`.
2. **Documentation (`README.md`, work log)**
   * Updated Korean and English shortcut references for `LT+RT+Y` and `LT+RT+L3+R3` (hold 1 s to quit).
